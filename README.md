## Публикация

GitHub Pages: `Deploy from a branch`, ветка `main`, каталог `/(root)`.
Custom domain: `diet.efreitor2001.ru`. Включить `Enforce HTTPS` после выпуска сертификата.

- Главная: `/`
- Политика конфиденциальности: `/privacy/`
- Удаление данных: `/privacy/data-deletion.html`
- SDK и сторонние сервисы: `/privacy/third-party.html`
- Оферта: `/offer/`
- Результат оплаты: `/payment/success/` и `/payment/fail/`
